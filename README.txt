MA MA ANNIVERSARY WEBSITE — REDESIGNED VERSION
================================================
Start date: 12 January 2024
Theme: Dreamy & Magical — pastel pink, soft yellow, white
Languages: Myanmar + English

WHAT CHANGED
- New full-screen opening design with a dreamy pink-gold gradient, orbit rings,
  moon, stars, large editorial typography, and a simple entrance link.
- From the Love Letter section down, the design is different:
  split-layout letter desk, redesigned envelope, promise-list chapter,
  and a contrasting rose-gold final surprise panel.

HOW TO RUN
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html and choose Open with Live Server.

ADD PHOTOS
Put your pictures in images/ and name them:
photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg

ADD MUSIC
Put an MP3 file in music/ and name it love.mp3.
Music attempts to start after the visitor clicks the opening button.

The relationship counter starts at 12 January 2024 and updates every second
using the visitor's device local time.
